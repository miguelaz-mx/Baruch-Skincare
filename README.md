# 🌿 Baruch Skincare

Sitio web oficial de **Baruch Skincare**, un proyecto enfocado en el cuidado de la piel y la estética facial.

##  Descripción

Baruch Skincare es una página web diseñada para presentar información sobre tratamientos de skincare y servicios estéticos de manera clara, moderna y responsiva.

El sitio incluye:

-  Página principal
-  Tratamientos
-  Preguntas frecuentes
-  Resultados
-  Sobre mí
-  Contacto

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

##  Estructura del proyecto

```text
Baruch-Skincare/
│
├── assets/

├── resultados.html

└── README.md
```

##  Características

- Diseño responsivo para celulares y computadoras.
- Navegación sencilla.
- Interfaz moderna y limpia.
- Optimización para GitHub Pages.
